******************************Streams_Features******************************
Java 8 Feature
Sequence of elements
Use to process collections(List, Set, Array) in simpler way(No Loops, No If-Else)
Its not a data structure, does not store data
Do not modify original data, create new processed result
Built support for parallel execution
Source -> Intermediate -> Terminal

******************************Stream Creation******************************
1. Using collections
2. Using Arrays
3. Using Stream.of()
4. Infinite Streams:
    1. generate()
            Generates values independently
            Uses a Supplier
            Use limit() to Stop
            Eg. Print Hello 10 times
    2. iterate()
            Generates values based on previous value
            Uses UnaryOperator
            Needs starting value
            Use limit() to Stop
            Eg. Print 1 to 100

*****************************Intermediate Operations******************************
1. filter() -> Predicate
2. map() -> Function
3. sorted() -> Comparator (Natural Order)
4. distinct() -> .equals()/hashCode()
5. limit()
6. skip()
