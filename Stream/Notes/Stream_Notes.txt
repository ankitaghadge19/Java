2. Using Arrays
3. Using Stream.of()
4. Infinite Streams:
    1. generate()
            Generates values independently
            Uses a Supplier
            Use limit() to Stop
            Eg. Print Hello 10 times
    2. iterate()
            Generates values based on previous value
            Uses UnaryOperator
            Needs starting value
            Use limit() to Stop
            Eg. Print 1 to 100

******************************Parallel & Sequential Stream*********************************************
-> Parallel Stream: parallelStream() (Multiple Threads)
Allowing multiple threads to process the parts of stream concurrently
Workload is distibuted across multiple threads
Use When: CPU-Intensive operations, Large data sets, Independent operations
Order not gauranted
Eg. Find Factorial of Number

-> Stream: stream() (Single Thread)
Create sequeantial stream(default)
Process elements one by one
Order is preseved
Eg. Cumulative Sum

-> Sequential Stream: Sequential() (Single Thread)
Forces Stream to Run Sequentially
Eg. Parllel Stream (Find Factorial of Nums) -> Parallel To Sequential -> Find Cumulative Sum of all Factorila Values

*******************************map() VS mapToInt()****************************************************

-> Stream<T> (Object)
Intermediatory Operations: map() 
Terminal Operations: .toList(), .collect()
( Stream<String> -> Stream<Integer> -> List<Integer> )

-> IntStream / LongStream / DoubleStream
Intermediatory Operations: mapToInt(), mapToLong(), mapToDouble
Terminal Operations: .toArray(), .sum(), .average()
( Stream<String> -> InStream -> int[] )

map() -> conatains boxed objects
mapToInt() -> contains primitives

Java stream never do boxing/unboxing silently.
Crossing between object and primitive streams must be explicit.

Boxing:    Raw -> Object, eg. int -> Integer
Unboxing:  Object -> Raw, eg. Integer -> int

split() -> Returns String[]
